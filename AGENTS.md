# Repository guidelines

This repository explores LLM reasoning through small, incremental experiments.

- Keep code simple, concise, and human readable. Prefer clarity over cleverness.
- Build one experiment at a time. Add only what the current experiment needs.
- Use clear names and straightforward control flow. Avoid unnecessary abstractions, wrappers, and configuration layers.
- Refactor working code when it improves simplicity or readability, preserving its behavior.
- Verify changes with checks appropriate to their scope. Keep experimental settings and results easy to inspect and reproduce.
